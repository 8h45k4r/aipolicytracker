# Security assessment, 24 September 2026

Scope: the whole repository at the head of the `claude/upbeat-archimedes-p1ubpl` branch, its git history, its
dependencies, its container base images, and the application running locally in production
mode (`APP_ENV=production`, `APP_DEBUG=false`) with the full corpus imported. Six scan types,
plus a manual code review of authentication, authorisation, billing, public forms, the public API
and the data importers.

The same scans now run in CI (`.github/workflows/security.yml`); see
[security-scanning.md](security-scanning.md) for when each one runs and how to read a failure.

## Findings fixed

| Severity | Finding | Fix |
|----------|---------|-----|
| Critical | Owner status came from `ADMIN_EMAILS` alone, so an unverified account on an owner address, or a profile email changed to one, became owner. | Ownership requires a verified email. |
| High | A password-only session, stopped at the second-factor challenge, could change the email or password or delete the account. | Profile and password routes sit behind `admin.2fa`; `confirm-password` is throttled. |
| Medium | Suspension, second-factor reset and password change left other sessions and remember-me cookies alive. | `User::endAllSessions()`. |
| Medium | A billing webhook that failed mid-apply was acknowledged as a duplicate on retry and never applied. | A retry of a failed event is re-applied. |
| Medium | Subscribe form could mail any unconfirmed address thousands of times a day. | Three confirmations per address per day. |
| Medium | `/og/site/{any}.png` wrote a new file per slug (disk exhaustion). | Only `default` exists; route throttled. |
| Medium | A trusted proxy let `X-Forwarded-Host/Port/Prefix` from the visitor rewrite generated URLs, including pagination links cached in public API responses. Reproduced: `https://evil.example:1/x/...`. | Only `X-Forwarded-For` and `-Proto` are trusted. |
| Medium | An admin could rename themselves to a published reviewer and sign verifications in that name. | Admin display names cannot be changed from the profile. |
| Medium | Subscribe confirmation and unsubscribe changed state on GET, so mail scanners could trigger them. | The link shows a button; the button posts. |
| Low | CSP and `nosniff` were missing on API responses and unmatched-route 404s; `X-Powered-By` exposed the PHP version. | Security headers are global middleware; `X-Powered-By` removed; `expose_php=Off` in the image. |
| Low | Full-table exports, `llms-full.txt` and social cards had no rate limit. | Throttled. |
| Low | CSV formula injection in exports of third-party data. | `App\Support\Csv` escapes formula cells. |
| Low | Array query parameters caused 500s; `page=1a` created cache rows. | Inputs coerced; page cast to int. |
| Low | `past_due` grace period restarted with each webhook. | Grace starts when renewal first fails. |
| Low | Scheduler, `/cron/*` and admin could run the same job at once (double digest). | Per-job lock in `JobRun::run`. |
| Low | `javascript:` URLs from the AI Incident Database could render as links. | Only http(s) at import and at render. |
| Low | Future-dated records reachable by slug; dotted slugs reached nested config keys. | `published_at <= now()`; slug pattern enforced. |
| Low | Flowbite loaded from a CDN without Subresource Integrity. | `integrity` hash pinned. |
| Low | Unbounded column index in the XLSX reader (memory). | Capped at Excel's column limit. |
| Low | The Docker image made `public/` writable by the runtime user. | Only `storage` and `bootstrap/cache` are writable. |
| Low | Third-party Actions pinned to mutable tags; unquoted workflow input. | Pinned to commit SHAs; input validated. Dependabot keeps them current. |
| Low | Session cookies not `secure`/encrypted unless configured. | Both default on in production. |

## Accepted, with reasons

- **Semgrep `laravel-dangerous-model-construction` (36 models with `$guarded = []`).** No controller
  passes unfiltered request input to `create`/`fill`; every write uses `validated()` or an explicit
  array. Reviewed 24 September 2026.
- **Semgrep `laravel-cookie-null-domain`.** A null domain is a host-only cookie, the stricter choice.
- **ZAP: CORS `*` on `/api/v1`.** The API is public, read-only and sends no credentials.
- **ZAP: `XSRF-TOKEN` without HttpOnly.** The front end reads it by design; the session cookie is HttpOnly.
- **ZAP: CSP `style-src 'unsafe-inline'`, `img-src https:`.** Scripts are nonce-locked; inline styles and remote images are not a script-execution path.
- **ZAP: no SRI on the font stylesheet.** The font CDN generates that CSS per request, so no stable hash exists.

## Not verifiable from the repository

- Branch protection on `main`, required reviews, required status checks and repository roles are
  GitHub settings; confirm them in *Settings → Branches* and *Settings → Collaborators*.
- The production database, host firewall and Cloudflare configuration were not tested.
