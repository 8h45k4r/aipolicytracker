# Funding

How this project is paid for and the rules that keep funding away from the data.

## Current funding

AIPolicyTracker is funded by the lead maintainer's own time and by Certifyi, the commercial
compliance platform the maintainer is associated with. There are no other funders or sponsors at
the time of writing.

The site's [funding page](/funding) shows the current funding picture and is kept up to date.

## Funding rules

1. **No editorial influence.** No funder, sponsor or subscriber sees a record before it is
   published, chooses what is covered, or decides how a record is described or whether it is
   verified.
2. **No early access.** Everyone, paying or not, gets the same data at the same time through the
   same public channels.
3. **No advertising or affiliate links.** The site carries no ads, no affiliate links and no
   vendor mentions in records.
4. **Data stays open.** The data is CC BY 4.0 on every plan and cannot move behind a paywall.
   Money pays for the service around the data (API limits, templates, support), never for the
   data itself.
5. **Funding is disclosed.** Every funding source is named on the site's funding page and in this
   file. An anonymous donation that cannot be disclosed is not accepted.
6. **Independence is structural.** The conflict-of-interest rules in
   [CONFLICT_OF_INTEREST.md](CONFLICT_OF_INTEREST.md) and the independent reviewer role in
   [GOVERNANCE.md](GOVERNANCE.md) exist so that no single funder, including Certifyi, can
   determine what the records say.

## Accepting new funding

Before accepting funding from a new source:

- The source is named in a pull request updating this file and the site's funding page.
- The independent reviewer (when active) is consulted on whether the source creates a conflict
  with existing records.
- The conflict-of-interest rules apply: if the funder is named in a record, the funder's
  representative does not approve changes to that record.

## Changing this policy

Changes to this file go through a pull request. The independent reviewer's objection is recorded
even if overruled. See [GOVERNANCE.md](GOVERNANCE.md), "Policy and governance changes".
