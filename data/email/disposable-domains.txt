# Domains belonging to services whose stated purpose is a throwaway inbox.
#
# Scope: a service that hands out an address nobody owns, that expires, or whose
# inbox is public. Anything a person keeps and can be reached at later is out of
# scope and belongs nowhere near this file — including alias and relay services
# (SimpleLogin, AnonAddy/addy.io, Apple's Hide My Email, DuckDuckGo, Firefox
# Relay). An alias that forwards to a mailbox its owner reads is a real address
# with a privacy wrapper, and refusing it would punish exactly the
# privacy-conscious readers this site is written for.
#
# Matching is by suffix, so "mailinator.com" also covers "team.mailinator.com".
# This list is deliberately short and hand-kept. It is not the defence on its
# own: most throwaway traffic arrives on rotating domains that no static list
# has ever seen, and is stopped by the mail-host and deliverability checks
# instead. See docs/modules/accounts.md.
#
# Operators can add to this without a deploy: see the overlay file named in
# config/email.php and `php artisan email:domains-refresh`.
